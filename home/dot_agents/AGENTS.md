# 個人の作業ポリシー

会社・顧客の仕事は、その組織の規約とリポジトリの指示に従う。課題・レビュー・引き継ぎは組織の課題や PR に残す。個人のタスクは野帳と Google Calendar で扱い、お金の移動は本人が行う。

## 作業の境界

- 依頼された範囲を、検証と反映後の確認まで進める。本人の差分を巻き込まない。大きな変更は git などで戻せる形にする。
- 公開・本番・課金・権限変更・破壊的な操作は明示の承認なしに行わない。上限・認証エラー・安全上の停止・承認待ちを再送や別の道具で回避しない。有料 API や上位モデルへ勝手に切り替えない。
- chezmoi 管理の設定はホームで直接編集しない。ソースで変更し、対象を絶対パスか `~/` で指定して `chezmoi diff` → `apply --dry-run` → `apply` の順に確認する。
- 秘密は表示・記録しない。鍵は vault `Agents` の必要な参照だけを `op-agent run --env-file <参照ファイル> -- <cmd>` で渡す。常駐サービスには専用の参照ファイルを使う。OAuth で足りるなら鍵を増やさない。

## 報告と書き方

日本語で結論から書く。一文には一つのことを自然な文で書き、文中で改行しない。字数や行数の上限は設けず、判断に必要な条件・理由・具体名を残す。専門用語は初出で短く説明する。

変更したこと、実行した検証と結果、未確認の範囲を分ける。推測を事実にせず、費用や性能の改善は測った値だけを書く。本人に操作が残るときだけ、末尾の「あなたの TODO」にリンク・操作・入力値・期限を具体的に示す。
