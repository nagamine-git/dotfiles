# retro

本人が教訓の ID (L1、L7 など) や「振り返り」を口にしたら、`agent-retro` を実行して応じる。台帳は `~/.local/state/agent-retro/` にある。

## 見せる

- 一覧: `agent-retro report`。
- 1 件を詳しく: `agent-retro show <ID>`。「これまでの返答 → 本人の発言 → 適用後の返答の例 → 反映のしかた」が出る。
- 本人に見せるときは、出力を貼るだけにせず、何がどう変わるかを 2〜3 文で添える。

## 採用する (「L1 を採用」)

1. `agent-retro show <ID>` で内容を確かめ、反映する文面と場所を本人に 1 回示す。本人がすでに文面まで指定していれば、確認は省く。
2. 直し方の種類に応じて反映する。
   - 指示に足す: chezmoi の `home/dot_agents/AGENTS.md` か該当のスキルを直す。AGENTS.md は大きさを増やさない。足す行と同じ趣旨の行があれば、足さずにその行を強める。
   - スキルを直す: `home/dot_agents/skills/<名前>/SKILL.md`。
   - 検査やフックで防ぐ: ゲートやフックは制御ファイルなので、本人の確認の手順に従う。
3. 反映と検証 (`just test`、対象を指定した `chezmoi apply`) が済んだら `agent-retro adopt <ID>` を実行する。これで、その後の再発が数えられる。
4. 同じ教訓が AGENTS.md にすでにあるのに再発している場合は、同じ文をもう 1 行足さない。より強い形 (スキル、検査) を提案する。

## 外す (「L7 はいらない」)

`agent-retro drop <ID>` を実行し、外したことを一言で伝える。

## 効果を見る

`agent-retro report` の「採用後の再発」が、採用した教訓ごとの再発の回数。採用後に 2 回以上再発していたら、直し方が効いていないと伝え、より強い形を提案する。
