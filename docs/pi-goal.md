# Pi の /goal

`/goal` は、本人がこのセッションの目標を1つ置くための拡張です。目標がある間は、ループの自動実行を含む毎回の実行で、目標がシステムプロンプトに追記されます。

- `/goal <目標>`: 目標を設定する (2000字まで)。
- `/goal` または `/goal status`: 現在の目標を表示する。
- `/goal done`: 本人が達成扱いにする。
- `/goal clear`: 目標を取り消す。

モデルが使えるのは `goal_control` の `status` と `complete` だけです。`complete` には検証済みの根拠が必須で、目標の設定・変更はできません。達成するとモデルは `loop_control` でループも止めます。目標は新しい公開・課金・権限の承認ではありません。

状態はセッションの現在の枝に `pi-goal` として残り、reload や resume で復元されます。拡張自体は時刻での実行をしません。

拡張の置き場所 (`dot_pi/agent/extensions/`) はゲートの制御ファイル扱いなので、追加と反映は本人の確認が必要です。テストは `python3 -B tests/pi-goal.py` (偽のPi 12件と、モデルを呼ばない実Piの登録確認1件)。
