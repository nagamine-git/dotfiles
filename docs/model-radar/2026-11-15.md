### 本人に知らせること (Pi)

- **default の基準で最安なのは GPT-6.1 Sol** (xhigh で 52 点 / $0.76、max で 55 点 / $1.27)。どちらも Opus 5.5 high の v4.3.2 のコスト ($1.82) と比べても安い。ただし strong が同じ gpt-6.1-sol なので、default にすると `modelThinkingLevels` のキーがぶつかり、段の重複にもなる。Sol を default にするなら、strong を別のモデルに替える判断が要る (strong は本人が選ぶ段なので、このルーチンでは変えていない)。
- Sol xhigh の 52 点は最低水準 52 点ちょうどで、版の違い (v5 / v5.0.1) で下回る可能性がある。max (55) なら余裕がある。
