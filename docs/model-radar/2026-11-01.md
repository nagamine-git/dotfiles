## 前提と注意

- **指数が両方とも新しい版になった**: Intelligence Index は **v5** (2026-10-27 公開)、Coding Agent Index は **v2.0** (2026-10-23 公開)。どちらも採点の中身が変わり、前回 (v4.3.2 / v1.5) の点数とは比べられない。比較は同じ版どうしで行った。
- **データの取り方**: 今回も artificialanalysis.ai (以下 AA) への直接アクセスは遮断された (curl は CONNECT 403、WebFetch は名前解決できず)。数値は、WebSearch の結果に出た AA のモデル別ページ・比較ページ・記事・X 投稿の文面から取った。グラフの目読みはしていない。一次ページの表は目で確かめていない。
- **AA のページで版が混ざっている**: 同じモデル別ページでも、effort によって v4.3.2 の値と v5 の値が混ざって出ている (例: Opus 5.5 low のページは 42 / $0.55 で、v5 記事では 35 / $0.98)。v5 の値は、v5 の記事と、v5 公開後の比較ページの文面で確かめられたものだけを使った。どちらの版か決められない値は「取得できず」にした。
- **依頼文とリポジトリの食い違い (本体の effort)**: 依頼文では本体は「effort medium (既定)」。リポジトリでは `dot_claude/private_settings.json.tmpl` の `modelSettings."claude-opus-5-5".effortLevel` が `"high"` になっている (2026-10-20 のコミット 1a95732 で変わった)。本体は medium と high の両方で評価した。
- **subagent のモデル**: Explore・Plan・general-purpose の定義 (`dot_claude/agents/*.md`) には `model:` が無いので、本体のモデル (Opus 5.5) を引き継ぐ。したがって今の割り当ては「Opus 5.5 / low」として評価した。
- **`dot_claude/CLAUDE.md`**: 今は `@~/.agents/AGENTS.md` を読み込むだけで、モデルや effort を書いた行は無い。`dot_agents/AGENTS.md` にも具体的なモデル名は無い。このため、書き換える行は無かった。
- **コストの意味**: AA が API の単価で測った 1 タスクあたりの金額。Max プランの利用枠をどれだけ使うかとは同じでない。
