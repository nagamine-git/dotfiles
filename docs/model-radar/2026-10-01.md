## 前提と注意

- **データの取り方**: この実行環境では artificialanalysis.ai・x.com・二次記事サイトへの直接アクセスがネットワークポリシーで遮断された。点数とコストは、WebSearch の結果に出てくる Artificial Analysis のモデル別ページ (下の URL) の内容から取った。一次ページの表は目で確かめていない。複数の検索結果で一致した数値だけを載せ、食い違うもの・出てこないものは「取得できず」とした。グラフからの目読みはしていない。
- **指数のバージョン**: Artificial Analysis は 2026-09 に Intelligence Index を v4.3.2 に改め、全モデルを数点低く採点し直した (例: Fable 5.1 max は 66 → 53)。この表は v4.3.2 の値だけを使う。Fable 5.1 の旧 v4.x の値 (low〜max = 58〜66, xhigh 65 / $2.72, max $3.76) とは比べられない。
- **依頼文とリポジトリの食い違い**: 依頼文にある割り当て (本体 medium、`dot_claude/agents/` の Explore・Plan・general-purpose = low、coder = Sonnet 5.5 / xhigh) は、リポジトリの今の状態と違う。下表は**リポジトリの実際の値**で評価した。
  - 本体: `dot_claude/private_settings.json.tmpl` に `"model": "default"` と `"effortLevel": "high"`。`dot_claude/CLAUDE.md` にも「親は Opus / high」とある。Claude Code の既定は medium だが、この設定で high になる。
  - `dot_claude/agents/` にあるのは deep-specialist (claude-fable-5-1 / high)、implementer (opus / high)、researcher (sonnet / medium)、reviewer (opus / xhigh) の 4 つ。Explore・Plan・general-purpose・coder の定義は無い。
- **役割の分け方**: 総合 (Intelligence Index) で決めるのは本体・researcher (Explore 相当)・deep-specialist (Plan 相当の判断役)。コーディング (Coding Agent Index) で決めるのは implementer (coder 相当) と reviewer (コードレビュー)。
- **コストの意味**: コストは Artificial Analysis が API 単価で測った 1 タスクあたりの金額。Max プランで実際に枠をどれだけ使うかとは同じでない (Opus と Sonnet の枠の消え方の違いは確かめていない)。
