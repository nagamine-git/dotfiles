## 今日の結論

Claude Code v2.1.257 に、現環境の構成に直接効くセキュリティ強化が2件同時に来た。(1) auto mode に「Containment Escape」ルールが追加され、クラウドメタデータ資格情報の取得・egress回避・テナント越境アクセスが環境側で明示的に許可しない限り自動承認されなくなった。(2) プラグインが宣言したパスがsymlinkの場合に自身のディレクトリ外を読めてしまうバグが修正された。どちらも `defaultMode: "auto"` を採用し、かつ外部リポジトリ製プラグイン(`freee-mcp@freee-mcp-marketplace`)を有効化している当環境の実害範囲に直撃する。あわせて Fable 5.1 が既定Fableモデルになり、`CLAUDE.md`のモデル配車則の前提が変わる可能性がある。それ以外のC(WM/OS)/D(業務SaaS)/E(ハード/インフラ)は無風。
