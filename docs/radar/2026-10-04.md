## 今日の結論

Claude Code v2.1.289 (10/3) で、`defaultMode: auto` のサンドボックスauto-allow下において、環境変数プレフィックス(例: `TZ="$HOME" rm -rf build`)や先行するbare変数代入でBashコマンドを隠すとdeny/askルールをすり抜けられていた穴が修正されたことが判明。本機の`dot_claude/private_settings.json.tmpl`はまさに`defaultMode: "auto"` + `permissions.deny`(`git push --force`/`gh repo delete`/`op item`等)という組み合わせで運用しており、直撃する穴が塞がれた形。他はHyprland/CachyOS/ROCm/Ghostty/freee系SaaS/Tailscale/Beszel/mise/lazygit/niri-river-swayいずれも既出判定から変化なし。Arch Linux 10月ISO(kernel 7.2.7, systemd 262)は一般Arch向けの通常月次更新で、CachyOS/EndeavourOS側の反映や本リポジトリのLUKS/TPM2設定もないため対象外。
