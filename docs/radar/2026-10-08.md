## 今日の結論

Claude Code v2.1.295 (本日10/8リリース) で、コマンド/HTTPフックに `onFailure: "block"` (フック実行自体が失敗した場合に許可側へフェイルオープンせずブロックする設定) が追加された。本リポジトリの `dot_claude/hooks/executable_injection-guard.sh` はPreToolUse Bashフックとして`curl|bash`等の危険パターンを拒否する自作ガードだが、現状はフック自身がクラッシュ(jq異常終了・想定外入力等)した場合の挙動が定義されておらず、フェイルオープン(ガード不在のまま実行継続)のリスクを抱えている。この新設定は直撃する穴を塞ぐため★★★とする。同リリースにはOSC 7501によるターミナル状態通知プロトコルも追加され、既存の`claude-tmux-status`tmuxプラグイン+自作`claude-statusline`の二重構成に対しターミナルネイティブな代替選択肢が増えた可能性があるが、Ghostty側の対応状況は未確認。他はTailscale(v1.104系詳細未確認、宿題継続)、Hyprland/CachyOS/ROCm/Ghostty/freee系SaaS/lazygit/niri・river・sway/Codex・Antigravity・Gemini CLIはいずれも既出判定から変化なし。
